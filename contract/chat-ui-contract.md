# Chat UI contract

## 目的

Altive Chatは、アプリ固有のデータ契約を共有せず、チャットの表示状態と操作契約を
SwiftUI、Flutter、Jetpack Composeで揃える。

## ライブラリが所有する責務

- メッセージ種別に応じた表示
- 自分と相手のメッセージ配置
- 単純なシステムメッセージ本文の中央寄せ表示
- 送信中・送信失敗などの表示状態
- 失敗時の再送導線と、アプリが実行する再送を受け付ける操作契約
- 入力欄、空文字送信の抑止、キーボード追従
- 入力欄は1行時にカプセル型に見える角丸とし、複数行時も角丸半径を深くしない
- 入力欄のフォーカス時に左側の添付ボタン群を折りたたみ、展開操作ではキーボードを
  閉じて添付ボタン群を再表示
- 複数画像の選択上限、送信前プレビュー、個別削除、テキストとの同時送信
- 写真ライブラリは入力面へ埋め込まず、OS標準の複数選択シートで表示
- ローカル／リモート画像メッセージの複数枚レイアウトと画像タップ通知
- 画像と本文を同じメッセージID、送信状態、再送単位で扱う複合メッセージ表示
- Character / UTF-16を選択できる入力長方針
- テーマとアクセシビリティ上の意味付け
- ファネリーのFamily Roomを正本とする吹き出し、システムイベントカード、入力欄
- アプリ固有の用途や永続化schemaに依存しない汎用メッセージカード
- キーボードとスタンプ入力面を切り替える際の共通レイアウト計算
- リアクション候補、件数、長押しpopoverと競合を壊さない楽観的更新
- 同じメッセージへ1人が複数種類のリアクションを保持でき、同じ種類の再選択だけを解除する操作結果
- ステッカーpicker、最近使った項目、アバター、システムイベントの展開表示
- ロック中のステッカーパックと履歴項目の表示、アクセシビリティ説明、利用導線callback
- ステッカーpickerは狭い画面で最低4列を維持し、横幅に応じて列数を増やす
- ステッカーpicker末尾へアプリ固有コンテンツを差し込む表示スロットとスクロール配置
- ステッカーpicker入力面を背後のタイムラインが透けない不透明背景で覆うこと
- 課金に依存しない汎用タイムライン境界
- アプリ固有の行を受け入れるタイムラインの初期位置、末尾追従、履歴追加時の位置保持
- タイムラインの初期位置は「末尾」または「指定項目とanchor」の型付き方針で受け取り、
  利用アプリごとの文字列scopeやnilの組み合わせへ意味を分散させない
- 履歴追加時の位置保持は、追加行のレイアウト反映後にアニメーションなしで復元する
- 通常起動の末尾、指定項目の中央、履歴追加後の位置保持を実ScrollViewで回帰検証する
- プラットフォームごとのPreview、Widget test、Screenshot test用fixture

## アプリが所有する責務

- 認証と現在ユーザーの解決
- Firestore、Storage、Cloud Functionsなどへの接続
- メッセージの永続化、実際の再送、削除、非表示
- ページング、既読更新、Push通知、Analytics
- 履歴追加の開始条件、取得処理、loading・retry・課金境界の表示
- アプリ固有ドメインモデルから表示モデルへの変換
- 権限判定と操作可否
- カメラ画面、画像の正規化・圧縮、一時ファイル、画像取得とキャッシュ
- 画像アップロード、画像ビューア、認証付き画像読み込み
- 課金判定、Paywallとアプリ固有画面への遷移
- ステッカーパックと履歴参照のロック判定
- アバターURL、ステッカーcatalog・assetの取得とキャッシュ
- ステッカーpicker末尾に差し込む販促内容、画像、外部リンクと遷移
- システムイベントの業務上の意味付けとアクション実行
- 削除済み・非表示などの業務状態からシステムメッセージ表示への変換
- 永続化されたカード種別・design IDから汎用メッセージカードstyleへの変換
- カードの見出し、本文、補足表示のローカライズと業務上の意味付け

## Swiftのモジュール境界

- `AltiveChatCore`はFoundationだけに依存し、表示値、入力方針、送信状態、
  楽観的更新などの純粋な値と遷移を所有する。
- `AltiveChatUI`はSwiftUI表示と一時的な展開・popover状態だけを所有する。
- Store、Repository、SDK、課金状態、権限、navigationは利用アプリが所有する。

ライブラリへは安定したIDと表示に必要な値だけを渡す。Firebase SDKやアプリ固有の
Store、Repository、Entityへ依存させない。

## Kotlinのモジュール境界

- `chat-core`はAndroid frameworkへ依存せず、表示値、入力方針、送信状態、
  楽観的更新などの純粋な値と遷移を所有する。
- `chat-ui-compose`はCompose表示と一時的なスクロール・dialog状態だけを所有する。
- `ChatTimeline`はSwiftUI版と同じ型付き初期位置、末尾追従、手動・自動の履歴追加、
  履歴追加時の位置保持を提供し、アプリ固有行は`LazyListScope`で受け入れる。
- Store、Repository、Firebase SDK、課金状態、権限、navigationは利用アプリが所有する。

## 並び順と識別子

- メッセージは作成日時の昇順で渡す。
- メッセージIDは画面表示中に変化させない。
- 楽観的に追加するメッセージにも、サーバー応答前から安定したIDを割り当てる。
- サーバー確定時にIDが変わる場合は、アプリ側で重複表示を防ぐ。

## 送信契約

- 入力値の前後にある空白と改行はライブラリ側で除去する。
- 空文字は送信コールバックへ渡さない。
- 送信コールバック呼び出し後、入力欄を空にする。
- 送信結果はアプリ側がメッセージの送信状態として再注入する。

## プラットフォーム差

状態、操作結果、アクセシビリティ上の意味を揃える。コンテキストメニュー、触覚、
キーボード挙動などは各OSの標準体験を優先し、ピクセル単位の一致を要求しない。

## 汎用メッセージカード

通常の吹き出しとシステムイベントカードの中間にあたる、送信者付きの強調表示には
`ChatMessageCard`を使用する。ライブラリはカードの外観、slot配置、テーマ、
アクセシビリティを所有し、利用アプリは用途、永続化payload、表示文言を所有する。

Firestoreの`messageKind`や`card.kind`など、利用アプリの保存値をAltiveChatの公開APIへ
持ち込まない。利用アプリが保存値を検証して`ChatMessageCardStyle`へ変換する。

公開API、style、fallback、test条件の正本は
[`message-card-contract.md`](message-card-contract.md)とする。

## SwiftUIデザインの正本

SwiftUIコンポーネントの形状、余白、配色、入力操作はファネリーのFamily Roomを
正本とする。ノコリスを含む利用アプリが独自に改善する場合は、先に
`AltiveChatUI`へ反映してからアプリへ適用し、実装の再分岐を避ける。

## 共通fixture

`fixtures/basic-chat.json`を最小の表示契約とする。各プラットフォームはfixtureを
固有の表示モデルへ変換し、同じ送信者判定、本文、送信状態を復元する。fixtureの
schemaを破壊的に変更する場合は`schemaVersion`を更新する。
